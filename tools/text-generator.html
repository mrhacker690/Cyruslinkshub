Quick Guide

📖 How to use this tool
1. Type your text in the input box
2. Pick gradient colors (2-6 colors)
3. Add formatting (bold, italic, etc.)
4. Choose font style
5. Copy the format you need!
🎨 Which format should I use?
&#rrggbb: Most plugins (LuckPerms, TAB, etc.)
<#rrggbb>: Chat plugins, MiniMessage
&x legacy: Essentials, PlaceholderAPI
§x console: Signs, books, command blocks
/tellraw JSON: Vanilla commands (1.16+)
[COLOR]: Forums, Discord BBCode
🔧 Advanced tips
• Use "Trim colors from spaces" for cleaner gradients
• Prefix/Suffix adds text before/after (like rank tags)
• Magic (&k) creates animated scrambled text
• Reverse button flips gradient direction
• Font styles work with all color formats
